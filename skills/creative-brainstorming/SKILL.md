# Creative Brainstorming

Use this skill when the user wants possibilities, not a polished final artifact.

## Goal

Generate useful creative range while preserving the user's taste, constraints, and existing material.

## Workflow

1. Identify the creative target: concept, plot, setting, character, name, scene, mechanic, or mood.
2. Extract constraints: genre, tone, audience, boundaries, must-keep details.
3. Offer varied options across distinct directions.
4. Name the appeal and tradeoff of each option.
5. When the user shows preference, narrow and deepen instead of continuing to scatter.

## Defaults

- Scale the number of options to the task; 5-8 is a useful default for open exploration.
- Avoid flattening unusual premises into generic safe versions.
- Keep options meaningfully different.
- Include one or two bolder choices when the user seems open to exploration.
- Do not over-explain unless the user asks for analysis.

## Output Format

Use compact lists with short rationale. For exploratory work, end with a recommended direction or a few promising combinations rather than a question-only handoff.
