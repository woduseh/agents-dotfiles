# Creative Revision

Use this skill when the user wants existing creative text improved.

## Goal

Improve the piece while preserving the user's intent, voice, genre, and emotional center. When in doubt, preserve voice before polishing style.

## Workflow

1. Identify revision mode and revision depth: light polish, style match, structural rewrite, tone shift, compression, expansion, or critique.
2. Preserve names, facts, continuity, POV, tense, and boundaries unless asked to change them.
3. Diagnose the main issue before rewriting: clarity, rhythm, tension, specificity, voice, pacing, exposition, or emotional logic.
4. Revise only as deeply as the request implies.
5. If useful, provide a short note on what changed.

## Revision Modes

- `Light polish`: fix flow, grammar, repetition, and awkwardness.
- `Voice-preserving rewrite`: keep style and intent while making it read better.
- `Tone adjustment`: shift mood without changing core events.
- `Structural revision`: reorder beats, sharpen escalation, or change scene focus.
- `Critique`: findings first, examples second.

## Principles

- Do not over-sanitize vivid or idiosyncratic prose.
- Preserve voice markers intentionally: sentence length, rhythm, diction, silence, repetition, and level of polish.
- Preserve productive ambiguity.
- Replace abstract emotion with behavior when it strengthens the scene.
- Keep dialogue character-specific.
- Ask before making major canon or POV changes if the user has not authorized them.
- For deep rewrites, state the main diagnosis and what changed; for light polish, keep notes minimal.
