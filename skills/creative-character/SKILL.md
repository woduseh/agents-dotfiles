# Creative Character

Use this skill when the character is the main creative problem.

## Goal

Create characters that perform consistently in scenes through drive, contradiction, voice, pressure responses, and relationships.

## Workflow

1. Identify the character's role in the work: protagonist, partner, antagonist, side character, ensemble member, or NPC.
2. Find the engine using relevant lenses such as desire, fear, wound, need, or current pressure without forcing every field onto every character.
3. Add productive contradiction: mask/leak, want/need, public/private, strength/blind spot.
4. Design voice: rhythm, register, silence rules, example lines, perception lens.
5. Map pressure responses: kindness, rejection, threat, intimacy, failure, being understood.
6. Scale detail to importance. Do not give every side character protagonist depth.
7. If writing for roleplay, include an opener that shows behavior instead of biography.

## Principles

- Behavior beats labels.
- Voice is behavior.
- Contradiction creates movement.
- Do not script future outcomes; define tendencies and thresholds.
- Facts matter only when they change performance, tension, or scene choices.

## Output Options

Choose the format that fits:

- Character concept notes.
- Full character sheet.
- Voice guide and sample lines.
- Relationship map.
- Opening scene/message.
- Diagnosis plus revision plan.

## Roleplay Characters

For LLM roleplay characters, first use any local project instructions available in the current workspace. Do not rely on absolute paths to external projects.

Use explicit scaffolding for control-heavy characters. Use self-introduction style when voice, omission, and self-presentation should carry more of the design. For cast-heavy bots, decide what belongs in always-on character text versus conditional lore.
