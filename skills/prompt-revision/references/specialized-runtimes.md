# Specialized Prompt Runtimes

Use this reference only when revising a prompt for a specific runtime, app, provider, roleplay system, preset, lorebook, toggle, or template pipeline.

- Discover and follow current local project instructions before changing syntax or structure. Do not rely on hard-coded external paths.
- Preserve runtime semantics before improving wording: block order, conditional syntax, variables, toggles, provider assumptions, insertion points, and output schemas.
- Distinguish always-on context from conditional blocks and keep activation rules explicit.
- Verify unfamiliar decorators, macros, or template syntax from current local documentation or user-provided material.
