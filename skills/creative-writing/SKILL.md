# Creative Writing

Use this skill when the user wants new creative prose.

## Goal

Write text that serves the scene's emotional movement, voice, and sensory reality. Avoid making prose overly tidy, generic, or explanatory.

## Workflow

1. Identify requested form: scene, dialogue, opener, monologue, vignette, description, or roleplay turn.
2. Preserve supplied facts, tone, POV, tense, and boundaries.
3. Choose the scene pressure: what is changing right now, what cannot be said directly, or what choice is narrowing?
4. Write through action, perception, subtext, and specific detail.
5. Leave interpretive room unless the user asks for explicit explanation.
6. For continuations, match the existing style before adding flourishes.

## Principles

- Scene first, exposition second.
- Dialogue should reveal intent, evasion, status, or desire.
- Description should carry mood and attention, not just inventory.
- Character voice may be uneven, evasive, excessive, or strange when that is the point.
- Do not smooth away the user's distinctive style unless asked.
- Let style serve the requested form; do not turn every creative task into a diagnostic checklist.
- If the user gives a fragmentary style, preserve its productive roughness before adding polish.

## Output

Usually provide the creative text directly. Add brief notes only when the user requested options, rationale, or revision guidance.
