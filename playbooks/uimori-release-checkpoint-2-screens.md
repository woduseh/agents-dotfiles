# Uimori 릴리스 체크포인트 2: 직접 볼 화면 체크리스트

PR #63–#70(2026-11-28 저녁에 병합)에서 "직접 확인해 주세요"로 남은 화면과 상태예요. 꼭 볼 것을 위에 두었어요.

## 꼭 볼 것

- [ ] 올린 직후 앱이 평소처럼 열리고, 예전 도우미 대화를 열었을 때 깨지는 곳이 없는지 봐요. 이 버전은 처음 열 때 도우미 변경 기록 테이블을 지워요. (#69)
- [ ] 도우미에게 장면 원문 수정, 번역만 수정, 플롯 쓰기, 작가 노트 쓰기, 채팅 로어 변경, 서재 자료 편집을 하나씩 시켜서, 답변 아래에 "저장됨" 결과 줄이 남는지 데스크톱과 좁은 화면에서 봐요. 예전에 변경 카드가 붙던 자리예요. 채팅 제목이 길면 줄이 두 줄로 꺾여요. (#69)
- [ ] 각 결과 줄을 눌러 장면, 플롯 작업 공간, "기억과 메모", 편집기가 열리는지 봐요. 채팅 로어 줄은 그 채팅만 열어요. (#69)
- [ ] 바깥 하네스(MCP)에서 실패한 실행을 하나 골라 "왜 실패했어?"라고 물어, 실패한 요청문과 모델 이름이 돌아오는지 봐요. (#68)

## 시간 날 때

- [ ] Story UI 테마를 도우미로 만든 뒤 고쳤을 때 미리보기가 마지막 줄 아래에 한 번만 나오는지 봐요. (#69)
- [ ] 두 탭 중 한쪽에서 도우미 대화나 프로젝트를 삭제한 뒤, 다른 탭에서 이름 변경, 프로젝트 이동, 요약 편집, 메시지 편집을 해 봐요. "다른 곳에서 삭제됐을 수 있어요" 안내가 뜨고 새 대화로 넘어가며 입력하던 글이 남는지요. (#67)
- [ ] 네트워크가 느릴 때 도우미 새 대화 만들기와 복사를 다시 눌러도 항목이 하나만 생기는지 봐요. (#67)
- [ ] MCP로 서재 폴더를 만들거나 옮긴 뒤, 열려 있던 서재 탭이 새로고침 없이 바뀌는지 봐요. (#68)
- [ ] 삭제한 채팅의 제목을 다른 탭에서 바꾸려 하면 충돌 안내가 나오는지 봐요. 예전에는 "찾을 수 없음"이었어요. (#68)
- [ ] Risu 카드를 하나 가져오고, Lua 스크립트가 있는 네이티브 카드로 장면을 하나 생성해 봐요. 같은 빌드 안에서만 하던 재검사를 걷어 낸 경로예요. (#65)

## 이번에 사라진 것 (확인용)

- 도우미의 변경 카드와 "이 턴 되돌리기" 버튼. 복구는 편집기의 직전 저장본 복원이나 백업으로 해요. (#69)
- MCP에서 삭제 도구는 아직 막혀 있어요. "삭제도 확인 없이 허용" 설정은 다음 작업이에요.

후보 커밋과 스냅샷 재생 결과는 `uimori-STATE.md`의 HANDOFF 블록에 있어요.
